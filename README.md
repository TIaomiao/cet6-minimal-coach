# CET-6 Minimal Coach

一个轻量级六级备考打卡工具。它不追求管理所有学习资料，只帮你每天完成一个能坚持的最小闭环。

## 项目结构

```text
cet6-minimal-coach/
  index.html
  style.css
  app.js
  README.md
```

## 怎么使用

在电脑上直接双击 `index.html`，用浏览器打开即可。

不需要安装 Node.js，不需要 npm，不需要后端，不需要数据库。这个项目只使用 HTML / CSS / JavaScript。

## iPad 上能不能用

能用，但要分清两件事：

1. 纯本地版：你可以把整个文件夹传到 iPad，用文件 App 或浏览器打开 `index.html`。这种方式最简单，但记录只保存在 iPad 当前浏览器里。
2. 静态部署版：把项目放到 GitHub Pages、Cloudflare Pages、Netlify 等静态托管平台后，iPad 可以直接打开一个网址。它仍然不需要后端，但记录还是保存在 iPad 浏览器的 `localStorage` 里。

也就是说：静态部署可以让 iPad 更方便打开网页，但不会自动让电脑和 iPad 共用同一份记录。跨设备同步需要后端、云数据库、Notion API 代理，或其他同步服务。

## 每日最小计划

- 听力 20 分钟：做一小段六级听力，对答案，找答案句，标记错因。
- 写作/翻译 15 分钟：
  - 周一、三、五：写作
  - 周二、四、六：翻译
  - 周日：复盘表达
- 打卡 3 分钟：记录今天完成了什么、错在哪里、明天要注意什么。

## 数据保存

记录保存在当前浏览器的 `localStorage` 中，键名是：

```text
cet6MinimalCoachRecords
```

这意味着：

- 刷新页面后记录还在。
- 换浏览器、换设备、清理浏览器数据后，记录可能不在。
- 数据只在本机浏览器里保存，本项目不会上传你的记录。

## 功能

- 显示今日任务、考试倒计时、连续打卡天数。
- 勾选听力、表达、打卡三个任务。
- 记录听力错因、写作/翻译问题、今日总结、明天注意事项。
- 写作/翻译问题已细化到主谓不一致、单复数误用、时态错误、冠词/介词错误、从句结构错误等。
- 自动保存当天记录。
- 显示最近 7 天完成情况。
- 统计本周最常见问题。
- 用本地规则生成今日建议，不调用 AI API。
- 一键填充示例数据，方便测试统计效果。
- 清空所有记录前会二次确认。

## GPT 反馈桥

你经常用 GPT 网页端或 iOS 端获得训练反馈，所以页面里加了一个“GPT 反馈桥”。

推荐流程：

1. 在网页里点击“复制 GPT 模板”。
2. 把模板发给 GPT，让它根据你刚才的训练反馈只输出 JSON。
3. 把 JSON 粘回“GPT 反馈或 JSON”输入框。
4. 点击“导入 GPT 记录”，它会写入今天的记录。

这个方案的边界很清楚：

- 它不需要后端，也不会暴露任何 token。
- 它需要你手动复制粘贴一次。
- GPT 网页端或 iOS 端不能直接写入这个纯前端网页的 `localStorage`，因为那是浏览器安全边界。

## Notion 与自动同步

如果你希望“GPT 反馈同时写入 Notion 和这个网站”，有三种现实方案：

1. 最小方案：GPT 输出同一份 JSON，你手动粘到网页，同时让 GPT 或 Codex 写入 Notion。
2. 中等方案：把 Notion 作为主记录库，做一个后端或 serverless API，由网页读取/写入 Notion。Notion token 不能放在前端代码里。
3. 完整方案：做登录、云数据库、Notion 同步、跨设备同步。这会变成真正的 Web App，维护成本也会上来。

当前项目仍保持“最小可坚持计划”，所以先采用第 1 种方案。

## 资料使用边界

本项目不爬取、不复制、不打包任何第三方真题、音频、视频或课程内容。

你可以把它和自己已经拥有的资料配合使用，例如班级群发的真题、已购买的星火英语资料、刘晓燕课程、新东方资料等。但这些资料的内容不应直接放进本项目仓库，尤其不要公开传播未授权的真题、音频或课程文件。

建议优先参考官方信息：

- 中国教育考试网 CET 报名通知：https://cet.neea.edu.cn/html1/report/2603/2-1.htm
- CET 考生须知 PDF：https://resource.neea.edu.cn/project/CET/News/CandidateNotice-CET.pdf?v=261.0
- CET 考试大纲：https://cet.neea.edu.cn/xhtml1/folder/16113/1588-1.htm

根据官方信息，2026 年上半年 CET 笔试日期为 2026-06-13，英语六级考试时间为 15:00-17:25。

## 之后适合怎么升级

如果只是你自己用，优先升级顺序建议是：

1. 先部署成静态网页，让 iPad 每天能打开。
2. 再做导出/导入或 Notion 手动同步。
3. 真的稳定使用后，再考虑 serverless + Notion API 的自动同步版。

不要一开始就做复杂系统。六级冲刺期，工具要服务执行，而不是吃掉执行时间。
